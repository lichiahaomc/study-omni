这是一道经典的正弦定理应用题,我们一步步来看 👇

思路:已知两边和其中一边的对角,用正弦定理求另一角。

解题步骤:
  1. 根据正弦定理:a/sin A = b/sin B
  2. 代入数值:√2/sin A = 2/(√2/2)
  3. 解得:sin A = 1/2
  4. 由于 a < b,所以 A < B = 45°
  5. 因此 A = 30° ✓
